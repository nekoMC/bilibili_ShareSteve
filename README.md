 1、实时获取弹幕 【已完成】
 通过node+websocket实现 
 使用目前的轮子可以拿到完整的弹幕json以及投喂礼物json（可以设计氪金玩法）
 通过弹幕json可以拿到用户名等信息
 弹幕json有效字段 
  text  : 弹幕内容
  uname : 用户名
